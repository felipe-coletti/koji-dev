# The TextMate grammar of Koji

`koji.tmLanguage.json` is the grammar of the syntax of Koji (`.kj` files, the scope
`source.koji`), in the format of TextMate, which many editors and highlighters read as it is:
Visual Studio Code (its extension, [koji-vscode](https://github.com/koji-language/koji-vscode),
copies it), Sublime Text, Zed, and the highlighters of GitHub and many sites.

It is kept here, next to the language, so that it follows the syntax: a change of the syntax
changes it in the same commit, and the editors copy it from here.
